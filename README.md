## Visão Geral
SisGT é uma aplicação desktop abrangente para gerenciamento de tarefas, desenvolvida com uma arquitetura modular para otimizar seu fluxo de trabalho. Construído sobre o .NET, oferece uma interface amigável para criar, visualizar, atualizar e excluir tarefas.

**Por que SisGT?**
Este projeto permite que desenvolvedores organizem e gerenciem tarefas de forma eficiente dentro de um sistema confiável e bem estruturado.Os principais recursos incluem:

- 🛠️ **Operações CRUD de Tarefas:** Criação, atualização e exclusão de tarefas com atualizações em tempo real na interface.
- 📦 **Arquitetura Modular:** Separação clara entre models, views e controllers, facilitando a manutenção e a expansão do sistema.
- 🚀 **Implantação & Configuração:** Oferece um processo de instalação simplificado através do instalador `.msi`, permitindo que o aplicativo seja instalado e configurado rapidamente sem necessidade de ajustes manuais.
- 🎨 **Interface e Recursos:** Organiza e gerencia elementos visuais como ícones, imagens e textos da interface, permitindo criar uma experiência agradável para o usuário, facilitando a adaptação da interface para diferentes idiomas.

## Primeiros Passos

### Pré-requisitos
Este projeto requer as seguintes dependências:
- **Sistema Operacional:** Windows 10 ou superior.

### Instalação
Baixe o instalador mais recente na seção de [Releases](https://github.com/PedroWatermann/SisGT/releases) do repositório.

Se você baixou o arquivo `.msi` do repositório para instalar o SisGT, siga os passos:

1. Clique duas vezes no arquivo `.msi` para iniciar a instalação.

2. **Atenção:** em alguns computadores, o **Windows Defender** pode exibir uma mensagem de aviso dizendo que não foi possível instalar.

3. Caso isso aconteça, clique em **Mais informações** e depois em **Executar mesmo assim**. O aplicativo **é seguro** e será instalado normalmente.

### Uso
Após instalar o SisGT (pelo instalador `.msi` ou a partir do código-fonte), você pode iniciar o aplicativo de uma das seguintes formas:

- Clique no ícone do SisGT na área de trabalho.
- Ou procure por "SisGT" no menu Iniciar do Windows e clique para abrir.
